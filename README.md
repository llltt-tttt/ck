## 技术栈

- 单文件自包含（`index.html`），图片全 base64 内嵌
- GSAP / ScrollTrigger 滚动动效
- anime.js 入场动画
- 无构建步骤，纯静态部署

## 本地运行

直接用浏览器打开 `index.html` 即可。
